Lors de la création d’un compte gratuit, GitHub.comvous pouvez également vous authentifier auprès de Google ou Apple, qui sont les fournisseurs de connexion sociale pris en charge. Pour les utilisateurs iOS, même si vous avez activé le paramètre « Masquer mes adresses e-mail » pour votre compte Apple, l’utilisation de la connexion sociale entraîne la création d’un GitHub compte. Chaque utilisateur de GitHub se connecte à un compte utilisateur. Votre compte utilisateur est votre identité sur GitHub, et a un nom d’utilisateur et un profil. Par exemple, consultez le [profil de @octocat](https://github.com/octocat). Plus tard, vous pouvez explorer les différents types de comptes qui GitHub offrent et décider si vous avez besoin d’un plan de facturation. Pour plus d’informations, consultez « [Types de comptes GitHub](/fr/get-started/learning-about-github/types-of-github-accounts) » et « [plans de GitHub](/fr/get-started/learning-about-github/githubs-plans) ». > [!NOTE] > Les étapes de cet article ne s’appliquent pas à Enterprise Managed Users ni aux utilisateurs sur GitHub Enterprise Server. Si votre GitHub compte a été créé par votre entreprise, vous pouvez ignorer cet article. ## Inscription à un nouveau compte personnel 1. Accédez à [https://github.com/signup](https://github.com/signup?ref_product=github\&ref_type=engagement\&ref_style=text). 2. Vous pouvez également cliquer sur **Continuer avec Google** pour vous inscrire à partir des réseaux sociaux. 3. Suivez les invites pour créer votre compte personnel. Lors de l’inscription, vous êtes invité à vérifier votre adresse e-mail. Certaines entreprises créent comptes d’utilisateur managés pour leurs utilisateurs. Vous ne pouvez pas vous inscrire à un compte personnel avec une adresse e-mail déjà vérifiée pour un compte d’utilisateur managé. Si vous rencontrez des problèmes lors de la vérification de votre adresse e-mail, vous pouvez effectuer certaines étapes de résolution des problèmes. Pour plus d’informations, consultez [Résolution des problèmes de vérification d’adresse e-mail](/fr/account-and-profile/how-tos/email-preferences/troubleshooting-email-verification). ### Résolution des erreurs d’inscription Si vous voyez `This email can't be used` ou `We couldn't create your account` essayez ce qui suit : 1. Utilisez un autre navigateur ou effacez les cookies et le cache de votre navigateur. 2. Désactivez vos extensions de navigateur. 3. Inscrivez-vous sur un autre appareil et réseau. 4. Attendez un certain temps, puis réessayez. Si vous voyez `This email can't be used`, essayez une autre adresse e-mail ou un autre domaine e-mail. Après avoir créé votre compte, vous pouvez ajouter ou modifier des adresses e-mail. Consultez « [Modification de votre adresse e-mail principale](/fr/account-and-profile/how-tos/email-preferences/changing-your-primary-email-address) ». Ces suggestions peuvent ne pas résoudre le problème. Support GitHub ne peut pas analyser les échecs de vérification de compte individuels lors de l’inscription. ## Étapes suivantes Nous vous recommandons vivement de configurer 2FA pour votre compte. 2FA est une couche de sécurité supplémentaire qui peut vous aider à sécuriser votre compte.
